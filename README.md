# AI Growth OS

A static, interactive presentation of a repeatable 90-day operating system for helping a small company adopt AI, improve revenue, and make the change stick. Furniture is one worked example, not the limit of the method.

The central argument is: start with measurable revenue or operating leaks, choose one workflow with the people who own it, prove the result with human approval, and scale only what earns trust. The public page is intentionally skimmable: a short answer first, a 90-day plan, a practical AI toolkit, trust controls, and proof of experience. Deeper diagnostic and value sections remain available for readers who want them.

No build step, no dependencies. Files: `index.html`, `styles.css`, `app.js`, `vercel.json`.

## Run locally
    npx serve .

## Deploy on Vercel
1. Push this repo to GitHub.
2. In Vercel: Add New > Project > import the repo.
3. Framework Preset: Other. Leave build command and output directory empty. Deploy.

Interview preparation notes are in `docs/interview-answer.md` (not part of the site).
